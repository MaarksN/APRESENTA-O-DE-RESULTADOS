# Diretrizes do Agente - APRESENTA-O-DE-RESULTADOS

## 1. Contexto do Projeto
- Este repositório gerencia as apresentações executivas e dashboards de resultados consolidados da **AtlasGR** e **Total Trac**.

## 2. Regras de Código & Desenvolvimento
- Escreva código completo de nível de produção. NUNCA use comentários como `// TODO: implementar` ou omita trechos de código.
- Mantenha o código HTML/CSS/JS limpo, altamente visual e responsivo.
- Use temas escuros elegantes (Dark Mode, Glassmorphism) com tipagem e gráficos interativos.
- NUNCA insira dados fakes/placeholders genéricos sem estrutura de KPI real (Receita, OKR, Churn, SLA).
- Respeite as fontes institucionais (Outfit/Inter) e gradientes corporativos da AtlasGR.

## 3. Qualidade de Código & Testes
- Todo código adicionado deve ser funcional imediatamente ao abrir o `index.html`.
- Preserve os links de navegação para os decks executivos `AtlasGR.html` e `Total Trac.html`.
